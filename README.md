# LWJGL Learning / Testing Project
A repo recording a Lecturer's ~~slow decline of sanity~~ techniques and thought processes whilst trying to learn their
first Graphics API.

## What is this project?
This project is an attempt to record my progress whilst learning OpenGL. This is for the purposes of providing insight
into how I approach learning new concepts. 

Additionally, I will do my best to note any major pitfalls I encounter during the process and, hopefully, how I overcame
them.
